# 实测结果与已知边界

记录范围：2026-09-28 至 2026-09-30，Windows，剪映专业版 11.5.0.14471，已登录且具有会员权益的本机环境。以下整理自历史实测，不表示其他版本、账号或素材都可用；本次文档整理没有重新运行这些实验。内部原始记录和测试素材不随仓库公开。

截至该轮验证，提供 17 个 MCP 工具和 CLI。已验证加密草稿读写、公开音色配音（含会员音色）、部分官方素材应用、批量修改及客户端继续编辑。**独立后台预览、导出仍未通过；成功的视频由剪映客户端界面导出。** 协议参数见 [原生协议](NATIVE_PROTOCOL.md)。

## 客户端导出与反复编辑

首次组合草稿长 9.566666 秒，包含两段画面、三段字幕、五段音频及一段特效。四类素材依次写入后，新增 ID、路径、类型、时长与完整加密读回均通过，源稿哈希未变。随后核对客户端 12 个编辑功能页，并在独立空白测试工程中打开、导出：

- 视频长 9.59 秒，720×1280，HEVC + AAC，2,733,805 字节；AAC 为 44.1 kHz 双声道。
- 整段解码通过，抽帧可见画面、字幕和转场，音轨波形非零；导出设置显示 3 项会员权益。
- 这不代表所有会员素材或复杂特效已完成渲染验证。

后续完整链路为“剪映保存 → 后台修改 → 剪映继续编辑 → 再保存 → 后台继续修改”：

1. 从加密草稿生成四个新版本：改第一句字幕、加入 2 秒贴纸、给第二句套字幕模板及字体、结尾追加 3 秒官方视频。每次加密保存并完整读回，原有 5 段音频、特效和转场保持不变，主媒体无缺失。
2. 在专门新建且已关闭的空白工程中验证项目及主时间线身份、零时长和零轨道，备份后填入根目录及主时间线的草稿文件。此实验不是通用导入器，不适用于任意已有工程或正在编辑的工程。
3. 客户端显示独立的贴纸、文字、视频和音频轨道；将贴纸从 40% 放大到 160% 后保存。
4. 客户端导出视频长 12.585011 秒，720×1280，HEVC + AAC，5,059,858 字节。完整音视频解码通过；1、3.2、11 秒抽帧分别确认改字与贴纸、字幕模板、城市视频。
5. 首次宿主波形返回不完整，被工具拒绝；改用完整 WAV PCM 解码确认有效音频，峰值 19672/32768。
6. 关闭工程后后台读回贴纸缩放为 1.6，再改字幕并加密保存、读回成功。最后这个文字变体没有重新导出。

字幕改字不会自动重新配音。测试沿用原布局，并未验证所有字幕位置或黑边处理。MP4 不保留逐轨编辑结构，不能代替草稿。草稿依赖本地图片、音频、字体、贴纸等资源，仍有绝对路径引用，不是可随意搬动的自包含工程。

## 批量编辑性能

2026-09-30 在同一台电脑做五轮同条件对照。输入为上述 9.566666 秒草稿，每轮改一句字幕、加 2 秒贴纸、应用字幕模板及字体、追加 3 秒视频。资源均已缓存，每轮包括原生加密保存与完整读回。

| 指标 | 分开四次调用 | 一次批量调用 |
| --- | ---: | ---: |
| 五轮平均时间 | 4.825 秒 | 1.403 秒 |
| 中位数 | 4.848 秒 | 1.371 秒 |
| 最快—最慢 | 4.399—5.171 秒 | 1.351—1.516 秒 |
| 每轮 MCP 调用数 | 4 | 1 |
| 每轮序列化响应量 | 8,300 字节 | 3,783 字节 |
| 成功情况 | 20/20 调用 | 5/5 批次，共 20 项编辑 |

批量约快 3.44 倍，耗时减少约 71%，响应字节减少约 54%。响应字节不是实际 token 计费数据；未做桌面操作的速度或 token 对照。

计时包含批内处理进程启动、编辑与加密校验；不含 MCP 首次连接（另测约 0.84–0.95 秒）、构思、在线下载、配音或 AI 生成、预览和导出。另一次时间线分页读取为 0.557 秒；贴纸布局与音量两项修改及加密保存为 0.559 秒。不能将这些数字等同于任意长度视频的制作耗时。

## 稳定性与保护范围

最新一轮 **28 项本地测试通过**，覆盖失败读回、源稿并发变化、目标目录并发创建、批内后一步失败、超时或响应错序、缺失字体、原音轨和未知字段保留。真实 MCP 另验证分页、布局与音量写回、中途失败、重名、越界及旧单素材工具兼容，并独立比对批量结果的字幕、时长和原音频、特效。早期阶段分别记录 9、13、19 项测试通过，属于不同阶段，不累加为额外覆盖。

- 批量支持 1–100 项受限修改，一次读取和最终保存；复用私有模型环境，每项素材操作重建 DataSdk 状态。
- SDK 会忽略部分原生字段并产生默认材料，因此只合并指定操作的变化和引用依赖；任何 `onAbort` 都判失败，即使返回 `ok:true`。
- 批量、普通改字、已缓存素材共用临时写入、完整读回、再次核对源稿哈希及目录改名交付；不覆盖已有或并发出现的目标，仅清理自己创建的临时目录。
- 旧 `make_portrait`、`add_catalog_asset` 尚未迁移到同一交付保护，失败可能留下工作目录；没有成功校验不能视为成稿。
- 不支持的操作、拼错字段、无效数值和缺失依赖会被拒绝；超时关闭自己的处理进程，不复用失去同步的会话，不自动下载或重新配音。
- 布局与音量修改已通过真实 MCP 和加密读回，本轮未新增视觉或听觉验证。

这是一台电脑、一个版本和短草稿的实验。未做长时间压力、大型工程、版本升级或旧版本兼容测试；参数上限 100 不代表已测过 100 项复杂素材的性能。

## 失败记录与剩余缺口

早期独立 addon 的 `material.list/search`、`asset.list/search` 返回 `unsupported_runtime_domain`；在线目录后来通过已登录宿主桥接接通。缓存检查发现 293 份包级配置，但三个资源数据库的 `effect` 表均为零行；配置数不等于完整素材数或会员素材数。选中缓存包缺少必要文件时停止写入，未以补造 ID 或跳过校验宣称成功。

完整时间线预览仍失败：隔离进程 `cefGpuState=unavailable`，GPU 返回 `-112`；取帧出现空数据或阻塞。已有视频 PNG 抽帧与音频波形已通过真实 MCP，它们不等于未渲染草稿的预览。

空会话 `exportDraft({})` 返回 `code=-3`；正确绑定后返回 `code=1`，但只观察到 `showWebMask`，没有完成文件。内部 CLI 导出入口存在，实际调用仍被 `-100015 unauthorized host process` 拒绝；最后一次以 15 秒超时参数调用，1.04 秒返回失败，无文件且源稿未变。未绕过鉴权，也未调用上传评估视频的流程。
